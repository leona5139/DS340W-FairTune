## Why `paired_*` runs

The original Stage-2 code evaluated the test set through a shuffled loader, so saved test predictions
were in a different order in every run and two models could not be bootstrapped on the same
resamples. `paired_*` cells re-run Stage 2 (same mask, same LR) with predictions dumped in a fixed order
after training; all runs of a dataset share one `(label, group)` array (the script asserts this).
Every cross-model comparison (T3, T4, F2, F3, T5) uses them; the original cells are still used for
everything produced by the search itself (masks, k-sweeps, timings, T2).

## Caveats to state in the paper

- **Stage-2 run-to-run noise.** Re-running the identical mask + LR changes PAPILA test worst-group AUC
  by 0.144 on average (median 0.167, max 0.417); Harvard-GF by 0.023 (max 0.081). Overall AUC moves
  0.049 (PAPILA) / 0.004 (Harvard-GF). On PAPILA this noise exceeds every between-method difference, so
  PAPILA worst-group numbers should be read with the seed SD and CIs, not as point rankings. This is also
  why the original and paired numbers for the same cell differ (e.g. ours on PAPILA 0.483 → 0.579).
- **No significant differences.** All Δworst CIs in T4 include 0 (PAPILA head-only is closest: upper
  bound +0.016). `seeds_beating_ours` in `data/T4_intersectional_ablation.csv` gives per-seed win counts.
- **TPE validation overfitting (single run).** Full TPE reached 0.914 validation worst-group AUC on
  PAPILA's 82 validation eyes; its test worst-group AUC was 0.417 in the original run and 0.667 in the
  re-run (46 test eyes, Young M has very few positives).
- **TPE runtime.** Measured 9.7 GPU-h (pause-corrected) vs 10.0 h extrapolated from 5 trials. 192 of
  200 trials were pruned, yet mean trial time stayed close to the sample's, so pruning saves little here.
- Worst/best = min/max over groups with both classes present on the test split.
- Bootstrap: stratified by group × label, 2000 resamples. Seed rows marked † are seed 0 only.
- Paper (ICLR 2024) numbers are not on this split or metric (they used per-batch AUC); compare only
  qualitatively and label them as such.
